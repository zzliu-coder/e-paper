# 合入与回退边界

**运行根目录 integrate.py；先检查，再 --apply。** 它支持审查固定提交7ce967e的Lab3、前次交付Lab4，以及具有完整未修改安装回执的统一试验台5。

工具逐一核验主应用、SDK/CMake、UI菜单和底层驱动。现有文件有其他修改就停止。安装时备份到 `.fontbench6-backup`，上一版安装回执也保留；写入异常会回滚已写文件。安装成功后再次执行不会重复嵌套补丁。

## 涉及的位置

- `main/inkdesk_app.cc`：统一试验入口、完整配置、原UI字号解析、目标灰阶帧读回与评分。
- `main/ui/fontbench/`：本包设备端实现。
- `main/display/lv_adapter_display.h/.cc`：声明与追加实验适配器。
- `main/boards/metalio-e-ink-4/esp_lcd_panel_ssd1677.c`：在普通画帧、复位、关机、删除前接入恢复保护；BUSY等待改成有界等待；末尾追加同板端口代码。
- `main/personal_sdk.cc` 与CMake：版本、命令清单、新C源文件。
- `tools/fontbench/`：本机工作台和SD样本，正常固件不把这些HTML和样本全部编进应用。

原 `main/ui_demo_fonts.c` 只读取并计算身份，没有修改；现有UI字形与原阅读器默认字体保持不变。页码旧脚本只作为兼容入口；实际操作统一使用参数按钮。

## 不同版本发生冲突

把这一包交给当前实施者，在其最新源码上逐处合并同名模块。不要强行以 `changed-source/main/inkdesk_app.cc` 覆盖一个包含后来工作的新文件。

`compat/stage12_patch.py` 记录了精确合入点。`changed-source/main/inkdesk_app.cc` 是针对固定身份生成的完整主文件，便于diff。所有驱动改动以原文件Git blob哈希为前提，分支名相同不能代替提交身份。

协议版本仍沿用ML1；新增 `inkdesk.fontbench.frame` 返回2bit提交目标快照。批量配置增加可选 `refresh: "full" | "fast"`，默认full；fast仅供实验显式控制，实际清理以设备回执为准。前端日常参数修改依然默认全刷。

回退优先使用你原来的已验证固件和完整独立源码工作副本。源码回退可参考 `.fontbench6-backup` 与 `.fontbench-install.json`；恢复前应先确认没有后续编辑，不要删除原评分文件或格式化SD。本包不自动恢复Flash。

## 构建检查工具

先激活你已有的ESP-IDF环境，再运行：

```sh
python3 app/check_firmware_build.py --repo /你的/e-paper --build-dir /独立/build-fontbench --build
```

此工具显式执行 `idf.py -B … build`，记录日志并核对构建输出；没有Flash、串口、分区写入和复位命令。未加 `--build` 时只检查工具链与合入回执。交付中的本次检查没有运行完整ESP-IDF，这一步仍必须在目标环境完成。
