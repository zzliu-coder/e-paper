# 怎么比较这次的新增方案

**先固定字体和字号，点「与原轮廓比较」；再点「同字黑白／灰阶」。** 这些都是同一个试验台里的按钮，旧页码不再是操作方式。

## 三个层次

| 层次 | 作用 | 本轮怎么处理 |
|---|---|---|
| 字体 | 决定笔画原本长什么样 | 保留八个黑体来源入口，缺文件或字重会直接显示不可用 |
| 画字算法 | 决定如何让轮廓落在像素上 | 原轮廓、自动黑白、字体自带黑白、自动标准、轻微对齐、字体自带标准 |
| 屏幕输出 | 决定是否保留灰色边缘 | 黑白和真实四灰阶实验；网页显示灰色不等于墨水屏已通过 |

## 两个基准

**原轮廓 O-N**：关闭 Hinting／网格微调、自动微调和额外笔画增粗。保留把轮廓画成像素所必需的栅格化。使用目标原生 px，禁止内嵌点阵替代。所有本轮 FreeType 候选统一显式关闭 CFF／autofitter stem darkening。

**固件原样 FW（UI）**：电脑读取 `main/ui_demo_fonts.c` 中已有的 A2 位图；设备直接调用已有的 `ui_font_a18/a20/a22/a25/a28/a30`，不重新生成，不调用近似字号映射，不允许替补字体。源文件 SHA-256 由合入工具写入身份头文件。离线样本版缺少原仓库时明确留空。

此基准覆盖现有 UI 的思源 Medium 字形、指标和黑白合成；真实阅读器使用的 MiSans fontpack 是另一条路径。本版不把 UI 基准标成阅读器基准，也没有修改原字体文件。16px、36px、40px 等原 UI 没有的精确规格会提示不可用。

## 按钮释义

| 按钮 | 参数 ID | 实际处理 | 墨色门槛 |
|---|---|---|---|
| 自动对齐 · 黑白 | M-A | 自动微调，MONO 直接黑白 | 不生效 |
| 字体自带 · 黑白 | M-N | 关闭自动微调，MONO 直接黑白 | 不生效 |
| 自动对齐 · 标准 | N-A | 自动微调、NORMAL、保留 A8 | 黑白输出时生效 |
| 轻微对齐 | L-A | 自动微调、LIGHT、保留 A8 | 黑白输出时生效 |
| 字体自带 · 标准 | N-N | 关闭自动微调、NORMAL、保留 A8 | 黑白输出时生效 |
| 原轮廓 · 关闭微调 | O-N | NO_HINTING＋NO_AUTOHINT、NORMAL、保留 A8 | 黑白输出时生效 |
| 固件原样 · UI | FW | 直接用现有 UI 字库 | 固定128 |

“字体自带”仍可能执行字体原本的微调。完全关闭微调应使用 O-N。

四灰阶第一轮固定线性四档：0、85、170、255。它们是**数字目标值**；实际屏幕的反射深浅尚未测量，不能称为已校准 Gamma。此模式下墨色门槛禁用。MONO 已经只有两色，选择灰阶输出也不会凭空产生中间层次。

## 推荐的第一轮

先用22px，固定一个真实载入的黑体，把 O-N 固定在 A，B 切换 N-A、L-A、M-A。再看18px和30px。对入围算法使用同字黑白／灰阶矩阵，最后检查反白与完整正文。每次只改变一个变量，感觉相同可以直接记录“相同”。

### 比较结果的含义

电脑三方像素一致：程序生成了预期的图。

设备目标帧读回一致：软件保存的、已成功提交给驱动的目标图一致。

肉眼确认：屏幕真能显示稳定灰色、文字更舒服、残影和速度可接受。最后这一项仍由真机完成。程序不会伪造这份结论。
