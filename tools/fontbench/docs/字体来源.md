# 黑体来源与证据边界

当前构建实际载入 Noto Sans CJK SC Regular/Bold；SHA-256、face index、实际字重和 FreeType 版本在 SD manifest 中。网络下载及 Mac 字库读取代码已实现，本环境没有外网下载通道与在线 Mac，以下额外字体没有被冒充为本次已经完成光学验证的候选。

| 条目 | 来源 | 载入方法 |
|---|---|---|
| 思源黑体 | https://github.com/adobe-fonts/source-han-sans | 仓库已有Medium；官方2.005R常规/中等/粗体URL |
| MiSans | https://hyperos.mi.com/font/zh/download | 官网取得后，在本机目录读取静态或wght可变版本 |
| HarmonyOS Sans SC | https://github.com/openharmony/resources/tree/master/fonts | 官方Regular/Medium/Bold路径 |
| 霞鹜新晰黑屏幕版 | https://github.com/lxgw/LxgwNeoXiZhi-Screen | 仓库已有字体；历史26.08.21发布 |
| 文泉驿微米黑 | https://github.com/anthonyfok/fonts-wqy-microhei | 仓库已有TTC/TTF |
| 苹方SC / 黑体SC | 用户本机macOS字体 | 使用本机授权文件；不分发字体软件 |
| Noto Sans CJK SC | https://github.com/notofonts/noto-cjk | 随包固定样文图片；有本机字库时可直接重算 |

思源和Noto同源；同一设计家族的不同字重是字重对照。Mac字体是否安装/可访问以实际扫描为准。下载失败时保留明确错误，不回退到另一字体。授权条件请依各原始字体许可；本包仅含固定样文和UI控件的栅格图，不包含字体文件。

算法参考：https://freetype.org/freetype2/docs/reference/ft2-glyph_retrieval.html 。所有候选显式设置 NO_BITMAP，禁止在某个尺寸悄悄切到内嵌点阵。原生微调不保证每个字体都含有效的微调指令，元数据如实记录原字体表。
