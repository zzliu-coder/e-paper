# 同板灰阶实现与来源

## 固定身份

本包基线：`zzliu-coder/e-paper@7ce967e28188ce28e9c4c0a3b2ae1b7c9e7896ea`。可自动升级对应 Lab3、前次交付 Lab4，或具有完整未修改安装回执的统一试验台5。用户修改过的目标文件会触发停止，不做模糊覆盖。

FreeInk SDK 参考固定于 `094976e1d47ad7120cf461fec5f6b737eaabf13f`。波形为该版 `Ssd1677Luts.h` 的 `lut_grayscale`，保留 MIT 许可于 `sources/FreeInk-LICENSE.txt`。本包沿用该固定上游灰阶 LUT 及其电压尾部，没有自行调整电压或搜索波形参数。该移植在本台设备上的电气与光学适配仍需真机验收。

## 渲染与控制器顺序

同一份 A8 样本可以产生黑白或四灰阶亮度。480×800逻辑画布映射到原生800×480：(nx,ny)=(y,479-x)。四灰阶亮度再转换成黑白主体、LSB、MSB三个平面。

| 亮度编码 | 黑白主体位（1为白） | LSB／BW RAM | MSB／RED RAM |
|---|---:|---:|---:|
| 黑0 | 0 | 0 | 0 |
| 深灰85 | 0 | 1 | 1 |
| 浅灰170 | 0 | 0 | 1 |
| 白255 | 1 | 0 | 0 |

此表为灰阶选择平面，和普通二进制亮度拆位不同。字形主体先显示，再以选择平面加灰阶。全刷首次使用F7；受控续刷FC；灰阶CC；灰阶提交完成后同步旧帧平面并以83关闭驱动电源。每个阶段等待BUSY，不能把上一阶段失败当成成功继续执行。

累计8次快刷后安排清理。回普通页面前使用保存的实际黑白目标进行完整清理，再恢复原驱动的快刷LUT和状态。原板配置为non_copy_mode=true，同时设置invert_color=true；原驱动在non-copy路径直接传原始字节，因此灰阶适配器保留同样的原始帧约定，不误把该标记当成需要额外翻转。

这是将同板参考适配到现有ESP-IDF/LVGL固件的实验实现。没有宣称二进制等同于完整CrossMux，没有替换其整个阅读器，也没有声明物理效果已通过。

## 文件边界

| 文件 | 职责 |
|---|---|
| `app/fontbench/raster.py` | 明确FreeType模式与原始覆盖率 |
| `app/fontbench/baseline.py` | 直接提取原 UI 字库的固定样文图像 |
| `app/fontbench/gray.py` | 数字亮度、旋转、平面参考算法 |
| `overlay/main/ui/fontbench/core.*` | 参数、四格样本、身份、评分、实验状态 |
| `overlay/main/ui/fontbench/device.h` | 原有 LVGL 组件及真实 UI 字库接入 |
| `gray/driver.c` | 独立可测的 SPI/BUSY 状态机；不分配内存 |
| `gray/panel_port.inc` | 追加到原SSD1677 C文件，使用实际私有结构 |
| `gray/adapter.inc` | 追加到原LVGL显示适配器，捕获并提交实验帧 |
| `compat/stage12_patch.py` | 带原文件哈希校验的精确合入 |

新增目标帧96KB、驱动平面192KB、灰阶临时画布384KB显式使用PSRAM或已有PSRAM Runtime。字体ROI和旧UI的原有缓冲另外计入。实际剩余内存与完整应用体积仍需目标构建／真机测量，不能直接以电脑内存代替。
