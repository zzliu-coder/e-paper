# 真机验收：只用统一字体试验台

**当前灰阶是可调用的实验驱动，尚未取得这台设备的物理验收。每次开机默认关闭。** 仅在已经确认面板为 Metalio GDEM0397T81／SSD1677 时启用；其他同尺寸屏不可据此套用。

## 在屏上操作

进入原来的「首页 → 设置 → 字体实验室」。旧入口直接进入同一个参数面板。

先看黑白与原轮廓。确认 SD 资源匹配、字体名字和字号正确，再点「启用灰阶」，随后点「色块」。四格应当是白、浅灰、深灰、黑的实心色块；此处不使用黑白网点模拟灰色。

再点「色块」回到文字，用「比输出」把同一份字形的黑白与四灰阶摆在一起。保持正常阅读距离、同一光线；从22px开始，再比较18px、30px。点「全刷」「快刷」会记录实际执行的刷新步骤，驱动可以把过多的快刷提升为清理刷新。

完成后点「恢复」：关闭本次灰阶实验，清理物理灰阶状态，恢复原显示模式。回首页、待机或关机时也有底层恢复保护。**这些恢复路径已做软件模拟，实机仍需逐项观察。**

## 在 Mac 网页操作

双击「启动试验台.command」，填实际仓库路径并读取字体。先把同版本 SD 资源复制到卡中，再使用原有 Metalio USB 服务连接设备。网页不会自行打开第二个串口，也不刷机。

「将当前条件应用到真机」一次发送整组参数。只有明确点「启用本次灰阶实验」才启用物理灰阶。

## 自动验收入口

从本包根目录执行，需设备已运行本版固件、原 USB 常驻服务已开启。输出目录须不存在。

```sh
# 仅黑白：算法、代表字号、精确原 UI 基准、像素读回、空闲检查
python3 app/device_acceptance.py --out evidence-device/mono-01

# 显式灰阶：色块、同字对比、正反色、10次交替样文的受控快刷、恢复
python3 app/device_acceptance.py --out evidence-device/gray-01 \
  --gray --panel GDEM0397T81

# 全部25个整数尺寸 × 6条轮廓渲染路径；刷新次数更多
python3 app/device_acceptance.py --out evidence-device/full-01 \
  --gray --panel GDEM0397T81 --exhaustive
```

脚本只修改实验界面，读取状态并把证据保存到电脑。不会点击视觉评分、刷写 Flash、修改真实阅读器字体或清除历史记录。目标帧读回为原生800×480、2bit、96,000字节；黑白页也按此格式编码。旧48,000字节接口继续保留。

## 出现异常时

停止继续切换参数，使用一次「恢复」。BUSY 长时间未释放时，驱动在10秒上限停止；恢复也先等 BUSY 释放，忙线仍高时不会连续写入或复位。保存错误日志，继续保留原固件备份。电脑测试模拟了通信失败、忙线超时、恢复和内存不足；这些不能证明物理接线、屏幕个体或波形观感。

**第三阶段保持未开始：先把人工确认表填完，再把胜出方案接到正式阅读器。**
