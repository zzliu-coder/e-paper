## 2. 此轮具体补齐

- 打开书先增量生成可用页面；重开命中经过 SHA 校验的分页缓存时，不重新读取章节 HTML。测试断言覆盖这一点。
- 缓存身份包含书内容、实际字体身份、补字字体、字号/字重/行距/视口和显示方式。坏缓存只重建派生文件。
- 新引擎位置使用“可见字符偏移 + 页提示 + 排版身份”，可区分没有新增文字的图片页；原引擎进度和书签单独保留。
- 新增中文“电子书排版”设置。旧设置文件继续使用兼容排版，避免升级后旧阅读位置被解释成另一种单位；全新设置默认图文排版。
- 书内链接可点击，并有“返回原文”；搜索按原章节可见文字扫描，跨行、跨页、跨标签不依赖排版拼接。
- 预览使用当前页文字；保存字号失败同时回滚字体、实际排版和位置。
- 坏图/缺图以占位或说明降级，后续文字和翻页仍可用；取消读已生成页面后，可以在同一会话重试。
- 元数据、TXT 索引、缓存校验、图文分页和搜索补进度/取消回调。加载提示继续走无需 SD 字库的中文救援字体。
- 图文/连续翻页/预备对照工具采用唯一请求回执，比较位置时包含页提示，避免图片页同文字偏移被误判；首次反馈只统计当前活跃加载任务，兼容引擎也保留图片页诊断字段。
- FAT 无法覆盖目标的 rename 行为已在电脑端模拟；只允许轮换派生缓存或受保护的双槽记录，书籍和字体不会因此被删除。

## 5. 安装后怎样看到变化

本轮未执行以下设备步骤。恢复设备测试时，先完成身份、安全状态、当前运行槽与更新清单检查。

1. 版本应显示 perf10。进入“系统设置 → 显示与阅读 → 电子书排版 → 图文排版”。
2. 打开含 PNG/JPEG 的 EPUB，看插图、强调、注音与链接；退出再进入，检查位置保持。
3. 点内部链接后用“返回原文”；改字号后检查大致原文位置与书签。
4. 电脑端 reader_content_acceptance.py、reader_navigation_soak.py、paper_loading_acceptance.py 收集操作与完成帧的对应日志。
5. paper_lookahead_compare.py 做 off/on/on/off 对照；实际速度和残影结果出来后才选择默认方案。

两套引擎分别保存进度，切到图文排版时可能从该引擎自己的上次位置或首页开始；切回兼容排版可以取回原有进度。不会静默转换单位不同的旧位置。

## 6. 明确边界

- 本轮没有取得设备开书秒数，不能宣称十几秒已降到几秒。已完成减少重复解析、按需分页与等待反馈的代码和回归。
- 实机速度、字体清晰度、残影、灰阶、蓝牙真实配对/声音、Mac 物理拔插/睡眠、完整恢复和八小时稳定性仍为 NOT_PROVEN。真实四灰阶门禁仍关闭。
- 支持上游有限 CSS 能力；不包含浏览器级布局、任意书内嵌字体、SVG/GIF/OCR或复杂文字塑形。合成粗体/斜体不是新增独立字库。
- 图片预算：压缩资源 <=1MiB、像素 <=512K、解码分配 <=3MiB。超限降级，不修改原书。
- 单缓存文件 <=16MiB、单章 <=4096 页、XML 深度 <=128。缓存积累在 SD，目前没有总量自动淘汰；需要释放时，应退出阅读后只清理 .paper/cache/crossmux-1/，保留 books、字体及 .paper/records。
- 首次书籍 SHA、第一次复杂章节解析、跨章回跳仍可能需要等待；进度与取消是合作式边界检查，不能强制中断一次底层 SD 调用。

以上是明确支持范围和物理验收边界；不能把“本轮软件闭环完成”扩大为“整机所有功能已经实测完成”。
