# clear1：正式文字柔化，移除清晰度对照

## 改动

- 对照页面、灰阶/笔画对照命令、菜单入口和实验帧缓存移出产品；历史页面在 experiments/font-clarity 保存。真灰阶 driver.c 不参与此配置构建，面板接口只保留正常黑白兼容函数。
- 设置 → 显示与阅读 → 文字显示：网点柔化（默认）/原始黑白。界面与两套阅读器共用 Canvas 字形覆盖率处理。面板仍黑白快速刷新，无新增全帧暂存。
- 柔化采用固定像素坐标 2×2 网点，覆盖率0/25/75/100%；纯黑笔画/纯白背景不变，不改字体文件、字重、字号、字宽、书签、章节缓存和页码。
- reader_gray 历史记录字段保留兼容读取，设置列表隐藏；本构建不支持真灰阶。SD字库与书籍不删除。
- 图像解码/图片网点算法未改。本轮仅将已接受的文字网点路线接入正式阅读。
