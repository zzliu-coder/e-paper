# grayab6：隔离显示控制器状态的修复候选

## 最终用户反馈

用户确认：真灰阶相对网点模拟没有明显视觉收益，白底仍不干净。物理质量验收 FAIL；不作为正式默认显示路径。后续 clear1 移除对照页并关闭实验驱动构建，历史源码和证据保留于电脑。

## 范围与依据

grayab4/5用户确认脏底/白屏，均为物理FAIL。此次保留常规400、黑白及网点方案，不恢复粗体或笔画微调。

从当前代码确认：旧路径沿用官方初始化及C4基准，再执行FreeInk灰阶叠加；两套刷新生命周期不完整一致。这是已确认的实现差异，尚未证明是白屏的唯一根因。

对照本地固定FreeInk源码及[Metalio专用说明](https://github.com/0x1abin/crossmux/blob/main/docs/engineering/metalio-eink4.md)，候选改为：BUSY空闲后，仅复位显示控制器并重新初始化；关闭RAM自动交换；FC黑脉冲→FC目标基准→CC灰阶→83停车。灰阶入口不再使用C4/3F路径。不改LUT字节、不调模拟电压、不改eFuse或OTP。FC包含读取面板OTP波形，不是烧写OTP。

每次灰阶均完整执行该流程，暂不追求快刷。显示超时后禁止继续写入或重复复位。退出仍恢复官方黑白驱动并全刷。正式阅读默认保持黑白。
