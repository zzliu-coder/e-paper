# perf9：离线补齐与验收记录

本轮范围：只改电脑中的代码、测试、构建和文档。**没有连接串口、操作蓝牙、刷写、擦除、修改 eFuse 或在真实 SD 上写入文件。** 设备最后一次已证实版本仍为 perf8b；perf9 为未安装候选。

## 本轮实现

| 项目 | 实现与边界 |
| --- | --- |
| 开书等待反馈 | 书籍 SHA、ZIP 目录、章节读取、DEFLATE 解压、内容解析接入统一进度/取消；沿用中文救援字体，无需 SD 字体即可显示。百分比是当前步骤，解析显示不定进度，不能当作整本书完成百分比。 |
| 取消与重试 | 分块解压每 16 KiB 检查；取消清空解压输出、释放文件和资源租约。取消不发布半成品章节。原位置/书签保护沿用已有测试。 |
| 字体重复准备 | 浏览字体家族不再清空全部字体缓存；应用字体仍重新校验所选字面，保留界面字库。没有降低 SHA/CRC 检查要求。 |
| 重启继续阅读 | 成功打开后保存最近书籍路径；启动恢复后可直接“继续阅读”。非法路径忽略，改名后更新记录；记录保存失败仍退出输入页并给出中文提示。 |
| EPUB 样式 | 原有实际 CrossMux CSS 解析器继续复用；添加强调、斜体、删除线、em/rem 首行缩进。强调/斜体是当前字面的合成表现，保持度量与 UTF-8 定位；作者显式 CSS normal 可以覆盖语义默认。图片分页和前后翻路径保留。 |
| 相邻字形预备 | 新增同章空闲预备实验，复用现有字形缓存，无第二套缓存。不跳转、不写位置、不跨章解压、不解图片。每轮最多 24 个字符、总窗口 384 个字符/约 48 KiB；字形之间检查输入队列和 8ms **软预算**，单次 SD 读取不能由它强制中断。默认关闭，尚未选择为最优策略。 |
| 蓝牙状态与电源 | CR/LF/分片回复解析、最近六条有界回复及接收计数；未识别连接通知时显示“状态待确认”。确认进入接收模式后保留供电，主动结束/切换/报错后释放，避免未知连接被两分钟闲置策略断电。实际接收连接通知格式仍需采集。 |
| 自动测试回执 | perf9 的 paper.command 支持 32 位十六进制 request_token；完成帧同时发布 token。主工具要求匹配 token、boot、动作、revision/presented；翻页还要求阅读位置改变。同名旧命令、停在字体页、页边界不再被算成翻页成功。 |
| 长稳脚本 | 开始阶段失败也写入失败记录；应用错误/字体错误/重启/丢包/超时不再漏报。边写日志边统计，不在内存保留八小时全部样本。 |
| 恢复材料 | 新增完全离线的整片备份校验工具，检查大小、独立留存 SHA、分区 MD5/范围、应用 checksum/hash。没有执行恢复或读取当前芯片安全设置。 |

## 已完成的检查

- Python unittest：20 项通过（含本轮回执、模拟八小时调度、异常记录、恢复镜像校验）。模拟时钟不代表设备运行了八小时。
- 原生测试：维护界面/资源仲裁、字体和阅读性能、EPUB 内容、离线取消/继续阅读、蓝牙、刷新状态机。
- 新增边界：各 EPUB 阶段第 1/3 次回调取消、解压中段取消、损坏所选字体后界面字体仍可用、斜体实际像素变化、缩进不改原文定位、预备不改变当前位置且可立即停止。
- 刷新模拟：首帧基准、连续快刷、周期清屏、灰阶回黑白、恢复、全部 BUSY 阶段超时及抽样 SPI 错误；错误后禁止继续假定显示基准有效。
- 原厂备份：16,777,216 字节，SHA `5b7986151b18163f9087611edfedd563c49e37c32c12d999d0e0fa3d82a1cfaf`；分区 MD5、ota_0 应用 checksum/hash 通过，ota_1 为空槽。详见 [离线恢复证据](evidence/PERF9_RECOVERY_OFFLINE.json)。
- ESP-IDF 5.5.4 编译 PASS；原生五项 ASan/UBSan PASS，无检测器报错。独立子代理同样复跑五项并完成错误注入复核，发现的四项均修复；详见 [独立复核](PERF9_INDEPENDENT_REVIEW_20260919.md)。
- 未安装候选：`artifacts/paper-perf9-offline-20260919/update.bin`，2,789,584 字节，SHA `d49e9d84f390c21fc346f125f213db1763dbe7637575bc3d912dbaa21c3cb44f`；应用槽约 47% 空余。日志副本保存在该交付目录 `evidence/`。不与 perf8b 的实机回执混用。

## 下轮明确怎么测

只有恢复设备操作权限后才执行以下工具；本轮没有运行：

- 安装前：确认设备身份/安全设置/现存运行槽，列出实际候选文件、SHA、地址、擦写范围及恢复候选。不要直接执行构建日志打印的全量 `flash_args`。
- 已安装 perf9 后：`host/paper_loading_acceptance.py` 测取消/冷暖开；`host/paper_action.py` 用 token 回执；旧 perf8b 会被新版主工具明确拒绝。
- 字形预备 A/B：先打开一本可继续翻页的书，再用 `host/paper_lookahead_compare.py --out <新的日志路径> --pages 3 --idle 2`。按 off/on/on/off 测，相同位置、相同等待时间；每组清字形缓存，保留索引和校验。成功结束恢复原位置与开关，失败停止并记录，禁止盲重试。不会自动选择默认。
- 八小时：`host/paper_stability_monitor.py --hours 8 --out <新的日志路径>`。它是只读健康采样，不能替代交互、物理效果或严格的泄漏证明。
- 恢复检查：`host/paper_recovery_check.py <16MiB备份> --sha256 <独立记录的SHA>` 完全离线；输出 PASS 只表示材料检查通过。

## 编译与复现

继续使用本地 ESP-IDF 5.5.4 和 Metalio 专用配置，不另下工具链。主机入口 `tests/paper-maintenance/CMakeLists.txt`；运行每个涉及 SD 的测试时使用新 fixture，禁止将设备挂载目录作为测试输出目录。

`offline_test <现有只读字体/词库根> <全新fixture根> <测试EPUB>` 在 fixture 中硬链接不可变资源，仅写 fixture 的书籍和记录；`performance_test` 会故意损坏其复制出来的字体，因此必须给全新独立目录。macOS 的 `/tmp` 为符号链接，受限存储测试应使用 `/private/tmp` 或工作目录的真实路径。
