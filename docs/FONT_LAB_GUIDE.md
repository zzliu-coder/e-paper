# Font Lab 4 真机操作

**入口：首页 → 设置 → 字体实验室。SD 放置 `/inkdesk/font-lab4` 完整资源后，新页即可加载。** 首次上机仍需用现有 ESP-IDF 构建和受控 app-only 更新。

顶部依次为算法、字体、浓淡、字号、阅读、刷新；上一页/下一页只在当前组内切换。点具体样本文字后，左侧黑标记及底部 S1/S2 编号表示当前样本，再点评价。没有 SD 资源、缺字、规格不符或校验失败时，样本不参与最佳效果评分。

算法页以同一来源与字号比较 M-A、M-N、N-A、L-A、N-N。浓淡页分别比较原始覆盖率阈值和同家族真实字重；位深子页从同一母版生成 2bpp/4bpp，对应白底与反白，最终仍为 I1。字号组每五档一页，覆盖全部 16—40 px。

阅读组保留完整正文；文字过长会分成明确的连续页。刷新组由明确按钮启动1或4组交替，分别2或8次重画，结束后回到相同目标样本。沿用现有调度器，真实全刷/快刷模式写入评价。

建议先看22px，再看18/16px；每次只改变一个变量。按“清楚、太细、太粗、粘连、相同”留下判断。`SAVED` 表示日志已写入 SD，`NO SAVE`/`LOG FULL` 表示失败/达到容量上限。

右上角 OLD/旧版保留原实验室。旧版位深页已改为确切30px的2×2对照，停止模糊归属评分；原25px字号映射错误已修复，规格缺失不替换为其他候选。旧实验室其余页面保留作为历史参考。

电脑可直接打开已知页：`python3 host/font_lab4_open.py --page 2`。通过 `font_lab4_list.py` 查询清单，通过 `font_lab4_export.py` 导出真实评价。新日志在 `/inkdesk/font-lab4-ratings.jsonl`，旧日志单独保留。

完整构建、来源、测试及限制见 [FONT_LAB4.md](FONT_LAB4.md)。真正四灰阶需要另行核实面板与波形；本轮没有启用未确认的面板驱动。
