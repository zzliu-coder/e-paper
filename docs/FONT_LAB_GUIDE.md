# Font Lab 3.1 实机对比指南

## 入口

开机后进入 `UI 样机首页 → 设置 → 字体实验室`。如果当前停在别的样机页面，先按左上角“返回”回到 UI 样机首页；“设置”页里的第一张卡片就是字体实验室。

进入后，顶部六个页签依次为：`字号`、`算法`、`反白`、`混排`、`实景`、`位深`。

## 本轮改动

- 增加第六个“位深”页，接入设备已有 `font_data` 中的 MiSans 字库。
- 对照 25 px/2bpp、30 px/2bpp、30 px/4bpp 三种覆盖率输入。
- A/B/C/D 四个候选仍保留：思源黑体阈值版、思源黑体 MONO 版、霞鹜新晰黑屏幕版、文泉驿微米黑。
- 统一版本标记为 `1.0.0-fontlab3.1`，电脑端可读页数、方案、字号和像素帧。
- 没有改写 `font_data`，没有替换首页或真实阅读器的默认字体。

这轮的版本对比要分两层看：`fontlab3 → fontlab3.1` 主要是补齐默认 UI 字库缺失字形并修正验收基线，整体字面不会突然换成另一套字体；真正有明显差异的字体/栅格对比在本页 A/B/C/D。位深页的 MiSans 是设备原有字库的覆盖率示范，单独记录，不把它算作本轮新字体。

## 推荐观察顺序

1. 在“算法”页固定 22 px，依次看 A/B/C/D。
   - A 与 B：同一思源字形，观察栅格算法差异。
   - B 与 C：观察普通黑体与屏幕版黑体的字面差异。
   - C 与 D：观察屏幕版与紧凑嵌入式字形差异。
2. 在“反白”页看同一字号的白底黑字和黑底白字，重点看小标签、数字、转角和细横。
3. 在“混排”页看中文、英文、数字、标点的基线、间距和缺笔。
4. 在“实景”页先看 18/22 px 的小标签，再看 30/40 px 的标题和按钮。
5. 最后在“位深”页比较三块 MiSans。这里的 2bpp/4bpp 是字库覆盖率输入，现有面板仍输出 1-bit 黑白；它用来判断轮廓是否值得保留，不代表真正四灰阶。

## 每个方案只记录四项

- `清楚`：笔画连续，中文和数字在正常距离可辨。
- `太细`：横、竖或反白边缘容易消失。
- `太粗`：相邻笔画粘连，内白空间消失。
- `粘连`：刷新后或黑底白字出现团块、断笔或明显残影。

比较时固定字号、观看距离和光线；先看白底黑字，再看黑底白字，最后看一次完整刷新后的残影。评价按钮会把选择写入 SD 上的 `/sdcard/inkdesk/font-lab.jsonl`；没有 SD 时页面仍可比较，但会显示保存失败。

## 本轮实际操作卡

每次只改变一个变量，按下面顺序做一遍即可：

1. 进入“算法”，点“全刷”，字号固定 22 px。依次选 A、B、C、D，四行内容保持不变。
2. 回到顶部选择你认为最好的方案，进入“字号”，按 16 → 18 → 20 → 22 → 24 → 28 → 32 → 40 px。记录从哪个字号开始“清楚”；更小字号只要出现一个关键字断笔，就记为该字号的边界。
3. 在同一方案、同一字号进入“反白”，先看白底黑字，再看黑底白字。黑底白字只要小标签无法连读，就记“太细”或“粘连”。
4. 进入“混排”，检查中文、英文、数字、标点是否同一基线，`Il1 / O0 / 8B / rn` 是否容易混淆。
5. 进入“实景”，检查真正会出现在首页的标签、标题、按钮和虚线；这一步决定能否推广到全局 UI。
6. “位深”只作技术观察：比较 2bpp 与 4bpp 的轮廓是否更完整，不评价为面板灰阶。

## 证据边界

电脑自动测试可以证明入口、状态、导航、帧读回、刷新错误和空闲稳定性。照片和肉眼才能证明光学清晰度、反光影响、残影和“哪一套更舒服”。真正的 4 灰阶需要另开面板驱动、波形和读回项目，本实验页不会宣称已经实现。
