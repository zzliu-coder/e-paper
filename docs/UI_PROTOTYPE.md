# 纸间 UI 交互样机 / inkdesk-ui3

分析起点见 [纸间设计系统 v0.1 草案](DESIGN_SYSTEM.md)，当前已实现的公共组件、渲染钩子及使用方式见 [UI_COMPONENTS.md](UI_COMPONENTS.md)。本版本不是整套旧页面的全面迁移，也不宣称物理校准已经通过。

基于已验证 r2.3 的原生 C++ / LVGL / Metalio E-Ink4 底座。
不是整屏图片或网页。文字、点阵数字、面板、按钮独立绘制；触摸、实体键和
Mac 协议均走原有输入队列。原版书库、笔记、诊断和 USB 服务保留。

## 历史 A/B 字体（保留用于回滚）

这组入口属于 UI3 历史样机，不是当前字体实验室的活动方案。

- A 精密黑体：思源黑体 Medium（默认）。
- B 文楷阅读：霞鹜文楷屏幕阅读版（陆标）。
- 点击后整页立即切换，可回首页、阅读示例比较；新一轮比较请使用“设置 → 字体实验室”。
- 只影响 UI 样机的全部中文字，不改变原版 EPUB 阅读器字体。
- 本次开机期间保留选择；重启默认 A，不写入 NVS 或 SD。
- 字号 18 / 20 / 22 / 25 / 28 / 30，从原始 OTF/TTF 生成，无旧位图缩放。

## 可操作页面

首页、示例书库、阅读示例、设置、字体主题、图案选择、说明页、组件校准页。
阅读示例支持连续文本分页、字号、会话书签、显示/收起工具；工具显隐保持正文布局。图案可选择并预览。
设置 → 校准与组件：文字、线框、网点、状态四个分组，以及同页全刷/局刷对照；均不写持久配置。
时间、电量、示例书目都标为示例；网络、音量、电源配置只展示说明，不伪报执行。
尚未绑定真实硬件的设置不会联网、播放、改休眠或写文件。

“打开真实 SD 书库”“打开真实设备诊断”“笔记”分别进入已有真实功能。
原版纸间首页点击顶部 INKDESK 标题可回 UI 样机。Mac 可执行 `inkdesk.ui.open`。

## 刷新和安全

无秒钟、循环动画和定时重绘。切页、首次进入、字体切换做全刷；同页操作使用
已有全屏局刷波形，每 8 次更新后的下一次交互做清屏。没有宣称硬件窗口局刷。
刷新期间暂停输入接收，旧事件版本不应用到新页。刷新失败不循环重刷。
诊断通道保留，可读 `inkdesk.status` 定位 `ui_demo` 状态与刷新错误。

编译、主机布局检查、固件读回、设备协议测试、物理观感分开记录。

800×480 横向帧缓冲；它不证明墨水颗粒已经正确显示，不等同于设备照片。
