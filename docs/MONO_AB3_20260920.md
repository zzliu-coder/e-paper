# 同屏常规/粗体实验

上一版样本文字为MiSans 400常规字重；标题与按钮另有较粗样式，不能把整个页面称为加粗。

新版monoab3在18/22/26/32px各页，白底与黑底均显示两排相同内容“清晨微光 Aa 012345”：常规400、粗体700。使用SD中对应的真实字重资源，没有人工膨胀冒充700。三种算法仍为原始黑白、弱笔画微调、网点模拟；所有输出走黑白驱动，故障真灰阶仍禁止，系统阅读默认不改。

入口：系统设置 → 开发与维护 → 字体清晰度对照。“换字号”循环4个字号和色块。“清屏比较”只要求当前页全刷，目标像素不改变；用于观察局部暗区，不表示已定位暗区根因。

缓存当前字号的一张2bit实验母版（96KB），切换算法复用同一字形；换字号重建，离开实验页释放。不改变日常阅读字体缓存或分区。

原生与ASan检查15个组合、二值输出、700墨色像素多于400、白底/黑底逐像素互补、清屏前后CRC一致和full标志；Python全量测试另行记录。实机视觉观感由用户比较，不以数字回执替代。

候选：3,045,568字节，SHA256 4837b75880266e14ad238919e0d8764a3640152a5469c6d3138ddce7e91da898。仅写0x80000应用槽，保留monoab2于0x580000。字库、书籍、分区表、启动程序、eFuse不改；SD原更新包归档保留。实际安装/测试结果随后追加。
