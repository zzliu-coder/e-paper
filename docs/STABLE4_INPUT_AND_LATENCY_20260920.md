# stable3 / stable4：输入与页面等待合并修复

## 范围和验收边界

用户要求把数字显示、页面卡顿、开书/续读和输入体验一起推进；不再进行8小时稳定性测试。保持现有中文PAPER组件、二值网点柔化、官方硬件和USB维护底座。原厂整片恢复往返及保存热点重连已有独立证据，不重复演练。

## 本轮改动

- 数量/页码：删除`%02zu`，使用十进制整数和补零；nano printf兼容性不再影响书库数量与页码。
- 同类扫描发现上传临时编号使用`%016llx`，改成固定16位十六进制转换，测试0、完整64位值及最大值。
- UI字库：75个字号/字重子集覆盖650个源码字符；生成器和发布前检查共用覆盖规则，包含头文件。保留动态书名、候选词的完整字体回退。
- 字体验证：PFV2固定哈希锚点从26份扩到75份，覆盖400/500/700、16–40px。打开只认证头部和索引，使用字形时认证相应数据块；不把未读取的数据块描述成已全文校验。字库字节不改，SD缺少索引仍有原全文校验路径。
- 连续输入：32项有界队列，固定按键在同一会话/布局内跨帧接受，最多合并32键绘制。切换布局、取消、确认等会话边界失效旧输入；候选选择保持严格帧和候选版本保护。
- 物理触摸：键盘固定键从触摸采样下沿直达输入队列，不等待LVGL/面板BUSY锁；整次按下/移动/抬起由该通路消费，避免LVGL重复提交。每次按下只入队一次，滑动和按住不重复。
- 按键震动：仅已入队物理键触发，沿用系统开关及35ms非阻塞定时脉冲；远程自动输入静音。震动表示入队，不代表候选计算或屏幕刷新完成。
- 队列内某键失败仍处理后续修正键，并报告首次失败；不静默丢弃尾部退格。
- 中文词典：独立4KiB索引/内容窗口，减少每个候选在SD上的交替定位读取；保留原2048条上限、去重、学习加权和排序。

## 已有结果

- stable3已安装0x80000、原始读回通过，boot `53f95da1a5bda437`。
- stable3英文7个输入事件（含退格）合并约3.239秒到最终画面；与逐键动作的最终帧CRC相同，拒收计数未增加。逐键参考合计约13.397秒。此项是设备命令/绘图验收，不能替代手指采样与马达触感观察。
- stable3目录首次动态字回退约6.700秒，其中字体验证约4.566秒（含约0.935秒进度画面）；据此扩展PFV2，避免只修静态“柔”字。
- stable3全拼`yuedu`逐键参考约31.827秒，前两键约11.844/13.040秒；用于stable4对照。
- stable3验收文件开始前已存在操作，`accept.jsonl`中的开书2.190秒和设置1.956秒不标成干净启动冷态成绩。
- Python226项通过；原生与ASan页面/输入、资源互斥、密码隐藏、字体分块认证及损坏检测通过；新增24组全拼/九键与旧逐条读取算法完整候选列表逐项一致。
